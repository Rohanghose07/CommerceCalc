COMMERCECALC PRO

Open index.html in a modern browser.

Features:
- Full standard calculator with keyboard, brackets, percentage, square root, square and memory controls
- 20 specialised commerce calculators
- Step-by-step formulas
- Mobile and desktop responsive design
- Dark/light mode
- Local calculation history
- Offline-ready PWA files

For full installation/offline support, host the folder on GitHub Pages, Netlify or Vercel.
